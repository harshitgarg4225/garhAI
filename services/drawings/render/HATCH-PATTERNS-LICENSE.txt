Hatch pattern definitions — provenance and licence
==================================================

`hatch_patterns.py` in this directory vendors the standard ISO/ANSI hatch
pattern line definitions (the `acadiso.pat` families: ANSI31, BRICK, EARTH,
INSUL, AR-CONC and the rest) as plain Python data.

They were extracted verbatim from ezdxf 1.3.4, via
`ezdxf.tools.pattern.load(measurement=1)`. ezdxf is already a dependency of
this service (see `services/pyproject.toml`); the definitions are copied here
rather than imported at runtime because `services/drawings/render/` must stay
importable without ezdxf — SVG and PDF export run in deployments that never
write DXF — and because a silent upstream change to a definition would
silently redraw every municipal sheet already issued.

`services/drawings/tests/test_hatch_patterns.py` re-reads ezdxf and fails if
the vendored table drifts from it, so the copy stays honest.

ezdxf is MIT-licensed. Its licence follows in full.
