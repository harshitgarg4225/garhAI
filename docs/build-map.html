The engineering is further along than the product. Eleven of twenty-five jobs are genuinely done and proven in a browser against a live stack. What is missing clusters in three places: asset depth, the AI layer never having met a real model, and everything commercial. Two of those are keys and content, not architecture.

Before anything else

The production deployment is running in dev mode

The deployed API has no SMTP_HOST, yet sign-in works. The only way that is possible is APP_ENV being dev or test, which switches on dev_echo_otp — the one-time sign-in code is returned in the API response body. Anyone who knows an email address on the instance can sign in as that person. It also relaxes the fail-fast secret validator and drops Secure from the refresh cookie. This is fine for the demo it is; it is not a thing to leave running once a real client's plot drawings are in it. Fixed by F-1 and F-2 below.

All 123 compliance values are unreviewed seeds

Eight rule-pack files, 123 values, 100% marked confidence: "seed" and review.status: unreviewed. No architect has read one. The product sells citable compliance; an architect who trusts a seeded setback or FAR figure and submits it to a municipal office is the failure that ends the company. This is a domain-review programme, not a sprint — D-9 builds the machinery it needs.

The field

Four of the five competitors sell pictures. One sells drawing.

Grouping them by the job they actually get hired for, rather than by their feature lists, makes the wedge obvious.

Product Hired to do Stops at What we take from them
Krea Turn a massing sketch into a seductive image, in real time An image. No model, no dimensions, nothing downstream. Latency as a feature — the render should feel live, not queued.
Gendo Turn an architect's sketch or viewport into a client-ready render An image, but architecture-aware and geometry-respecting. Structure-preserving control, so the render is this building.
ArchiX Concept massing and visual exploration Concept. No compliance, no drawing set. Speed of exploration; option boards.
xFigura Generate floor-plan layouts from a brief A plan image or light vector. No bye-laws, no submission set. Brief → plan as a first-class entry point.
Rayon Be the collaborative drawing tool — real 2D CAD in a browser, multiplayer, deep block library Drawing, well. Not Indian bye-laws, not a municipal set, not AI generation. Everything about the editing loop, and the library depth.

Competitor characterisations come from the research pass earlier in this project and are pitched at the level of the job served, not the feature list — feature lists move weekly and the job does not.
