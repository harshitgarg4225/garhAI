# DECISIONS.md — deviation log

Every departure from the playbook gets a line here: **what** changed, **why**, and
**which playbook section** it touches. Same for **every new dependency** — that rule
is from SKILL.md ("Add a line to `DECISIONS.md` for every new dependency") and
exists so a licence question can be answered from this file alone, without
archaeology through lockfiles.

**Never deviate on:** the locked stack decisions, licence rules (Apache/MIT/BSD/MPL
only, never GPL/AGPL), LLMs-never-emit-geometry, tenancy scoping, or integer-mm
geometry. Those are not tradeable, and nothing below touches them.

### What was actually executed during the scaffold

Being precise about this, because "scaffold written" and "scaffold works" are different claims:

- ✅ `make help`, `make secret-audit`, `make tenancy-audit`, `make license-check`, `make dev-keys` — all run, on GNU Make 3.81 + Python 3.9.
- ✅ The licence scanner was validated against real metadata: it correctly clears MIT/BSD/Apache/MPL and LGPL, and flags GPL/AGPL. An early substring version produced false positives on numpy and pandas (their `License` field embeds full licence text mentioning the GPL); the shipped version reads SPDX `License-Expression` and trove classifiers instead.
- ✅ The JWT dev-key path was verified end-to-end: `make dev-keys` → single-line PEM with literal `\n` → the `\n`-unescaping `config.py` performs → `openssl pkey` parses it as a valid 2048-bit RSA key.
- ✅ `tenancy-audit` was proven to have teeth: its first run flagged `apps/api/garh_api/tenancy.py`, which is the repository layer itself and is now an explicit allowance.
- ❌ Not run: `docker compose config`/`up`, `pnpm install`, `eslint`, `tsc`, `ruff`, `mypy`, `pytest`, Playwright, and the CI workflow. `docker-compose.yml` could not even be YAML-parsed locally (no PyYAML), so it was reviewed by hand — the folded block scalars in `api.command` and `minio-init.command` deliberately keep every line at one indentation level, because a more-indented line in a `>` block retains its newline and would change the script the shell receives.

### How to add a dependency

1. Check it against `references/market-research-and-oss-licenses.md`. Apache/MIT/BSD/MPL
   only. GPL/AGPL is not a discussion.
2. Pin the exact version — no ranges, anywhere.
3. Add a row above, with the licence and one line on what it is for.
4. Run `make license-check`. If it reports the package as **unknown**, that is a real
   legal unknown: find the licence, and if the metadata genuinely omits it, add the
   name to `.license-allowlist.txt` **and** a row to this file explaining what you
   verified and how.
